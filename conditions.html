Conditions de vente

Dim Ticket Market — version provisoire, susceptible d’évoluer après concertation avec les organisateurs.

1. Réservation et paiement

La réservation est confirmée une fois le paiement reçu et validé par Dim Ticket Market. Votre billet apparaît alors dans Mes billets.

2. Annulation d’un événement

Si un événement est annulé, les billets seront remboursés après concertation avec l’organisateur. Les modalités de remboursement vous seront communiquées sur WhatsApp.

3. Remboursement à la demande du client

Vous pouvez demander le remboursement de votre billet sans avoir à vous justifier. Dans ce cas, vous serez remboursé à hauteur de 80 % du prix payé.

La demande doit être faite avant le début de l’événement, sur WhatsApp, en indiquant votre code de réservation (DTM-…).

4. Billet perdu

Votre billet n’est jamais perdu : retrouvez-le à tout moment dans Mes billets. Sur un nouveau téléphone, il suffit de taper votre code de réservation.

5. Utilisation des billets

  • Chaque billet possède son propre QR code, valable pour une seule entrée.
  • Ne partagez pas votre QR code : la première personne qui le présente à l’entrée est acceptée, les suivantes sont refusées.
